# Java OOP Lab Experiments

A collection of Java programs demonstrating fundamental Object-Oriented Programming concepts through a series of practical experiments.

## 📚 Experiments

| Experiment | Topic                           | Concepts                                                  |
| ---------- | ------------------------------- | --------------------------------------------------------- |
| Exp 1      | Student Class                   | Classes, Objects, Constructors                            |
| Exp 2      | Student Methods                 | Methods, Method Overloading                               |
| Exp 3      | GraduateStudent extends Student | Inheritance, `extends`, `super()`                         |
| Exp 4      | Method Overriding               | Overriding, Runtime Polymorphism, Dynamic Method Dispatch |

## 🧠 Concepts Covered

* Classes and Objects
* Constructors
* Instance Variables
* Methods
* Method Overloading
* Single-Level Inheritance
* `extends` keyword
* `super()` constructor
* Method Overriding
* Runtime Polymorphism
* Superclass References
* Arrays of Superclass Type

## ▶️ How to Run

Make sure Java is installed on your system.

Compile:

```bash
javac Main.java
```

Run:

```bash
java Main
```

For each experiment, navigate to its respective directory before compiling.

## 🎯 Learning Objective

These experiments demonstrate how Java's Object-Oriented Programming features work progressively, starting from basic classes and methods and moving toward inheritance, method overriding, and runtime polymorphism.
